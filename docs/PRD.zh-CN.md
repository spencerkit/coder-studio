## 1. 产品概述

### 1.1 产品定义

Coder Studio 是一款本地优先的 AI 编码工作台，将 AI 驱动的代码生成 Agent、代码编辑、版本控制和终端访问整合到一个统一的开发者界面中。它使开发者能够在单个工作区内编排 AI 编码 Agent（Claude、Codex），并与传统开发工具协同工作。

### 1.2 产品愿景

为开发者提供一个集中式工作台，让 AI Agent 和人类开发者能够实时协作编写代码，并对 Agent 活动、文件变更和终端输出保持完全可见。

### 1.3 核心特征

- **本地优先：** 运行在用户本机；所有代码、终端和 Agent 进程均在本地执行。
- **多 Agent 支持：** 支持在单个工作区内并行运行多个 AI 编码 Agent 会话。
- **全栈开发环境：** 将代码编辑、Git 操作、终端访问和 Agent 编排集成在一个界面中。
- **抗干扰：** 提供专注模式，隐藏非必要的 UI 元素，让用户可以集中注意力工作。

---

## 2. 目标用户

### 2.1 主要用户

**专业软件开发人员**，他们在日常工作中使用 AI 编码助手（Claude Code、Codex），需要一个专用环境来在代码、终端和版本控制之间管理多个 Agent 会话。

### 2.2 次要用户

- **技术负责人**：审查 AI 生成的代码和 Agent 进度。
- **DevOps 工程师**：管理带有 AI 辅助的本地开发环境。

---

## 3. 核心价值主张

| 需求 | 解决方案 |
|------|----------|
| 同时管理多个 AI Agent 会话 | 多面板 Agent 工作区，支持并行会话 |
| 实时查看 Agent 的动态 | 每个 Agent 嵌入独立终端，实时输出流 |
| 审查和编辑 Agent 生成的代码 | 集成代码编辑器，支持文件浏览和差异对比 |
| 追踪和提交 Agent 变更 | Git 集成，支持暂存、差异审查和就地提交 |
| 在 Agent 工作旁运行命令 | 多标签终端面板，包含 Agent 专属终端和 Shell 终端 |
| 在 Agent 长时间运行时保持专注 | 专注模式、完成通知、Supervisor 目标追踪 |

## 4. 信息架构与多形态外壳

应用按视口宽度选择两个**外壳（Shell）**之一：

- **DesktopShell**：当 `window.matchMedia('(max-width: 899px)')` 不命中时启用。
- **MobileShell**：当视口宽度 ≤ 899px 时启用，专为触屏交互设计。

两套外壳共享路由表、同一组数据流（Jotai atoms）和同一组 WebSocket 命令；差异在于布局与导航容器。

```
Coder Studio
├── 认证页面 `/auth`（鉴权启用且未登录时）
├── DesktopShell
│   ├── 顶栏（始终可见）
│   ├── ConfigDriftBanner（非设置页且检测到 Codex 配置干扰时）
│   ├── 连接状态横幅（断线/重连）
│   └── 内容区域
│       ├── 欢迎页 `/`
│       ├── 工作区页 `/workspace`
│       │   ├── 左侧面板：代码侧边栏（文件 / Git）
│       │   ├── 中央面板：Agent 面板树（可分割）
│       │   └── 底部面板：终端
│       ├── 设置页 `/settings`
│       └── 404 Not Found（任意未匹配路径）
├── MobileShell
│   ├── 顶部移动顶栏（工作区切换 / 设置入口）
│   ├── 当前激活会话主区
│   ├── 底部导航 Dock（Agent / 文件 / 终端）
│   ├── 文件、终端、Agent、Supervisor 等以 MobileSheet 浮层呈现
│   └── 同样的 `/`、`/auth`、`/workspace`、`/settings`、404 路由
└── 全局浮层
    ├── 命令面板
    ├── 工作区启动浮层 / 移动端 launch sheet
    ├── 分支快速切换（BranchQuickPick）
    ├── 确认对话框
    ├── Worktree 弹窗
    ├── Supervisor 目标对话框 / Supervisor sheet（移动）
    └── Toast 通知容器
```

### 4.1 路由结构

| 路由 | 说明 |
|------|------|
| `/` | 欢迎页（未打开工作区时进入；移动端启动入口） |
| `/auth` | 登录页；仅在后端 `auth` 已配置且未通过校验时跳转到这里。后端在 SPA 路由保留 `/login` 路径供未来切换 |
| `/workspace` | 主工作区页面；当前激活工作区由前端状态 / URL 参数解析 |
| `/settings` | 设置页面 |
| `*` | 404 Not Found 页面（显示请求路径与"返回首页"按钮） |

> **注：** 后端 `web-ui-routing.ts` 在 SPA 路由中保留了 `/api/`、`/internal/`、`/assets/` 等前缀，避免前端路由与后端 API 命名冲突。

### 4.2 引导流程（useWorkspaceBootstrap）

每个外壳挂载时执行：

1. 拉取认证状态；未通过则替换跳转到 `/auth`。
2. 已通过认证则同步本地工作区列表与会话状态，重连 WebSocket。
3. 失败时显示 `app-loading-shell`，并在恢复后跳转到上次激活的工作区。

## 5. 桌面端全局 UI 框架

### 5.1 顶栏

顶栏是应用顶部的一条持久水平条（高度 36px），只要至少有一个工作区打开就会显示。

#### 5.1.1 布局

顶栏分为两个区域：

- **左侧区域：** 工作区/会话标签
- **右侧区域：** 操作按钮

#### 5.1.2 工作区/会话标签

每个打开的工作区用一个标签表示，包含以下元素（从左到右）：

1. **状态指示点：**
   - 工作区活跃运行时：彩色圆点带有持续的脉冲动画（透明度每 2 秒在 1.0 和 0.5 之间振荡）。
   - 空闲时：静态彩色圆点，无动画。
   - 颜色映射：活跃 = 绿色（`#78d7b2`），空闲 = 灰蓝色。

2. **标签文本：** 显示工作区名称。过长时以省略号截断。

3. **未读徽标（条件显示）：** 显示该工作区未读消息的数量。以数字显示（最大显示为 "9+"），位于小型圆角徽标内（最小宽 16px，高 16px），背景为强调蓝色。数量为零时隐藏。

4. **关闭按钮（X）：** 默认隐藏，鼠标悬停在标签上时出现。点击关闭该工作区标签。

5. **添加按钮（+）：** 28×28px 的加号图标按钮。打开新的工作区标签（启动工作区启动浮层）。

#### 5.1.3 标签交互

- **切换标签：** 点击任意标签切换到该工作区。
- **关闭标签：** 将鼠标悬停在标签上显示 X 按钮，点击关闭。
- **新建标签：** 点击 + 按钮打开新工作区（打开工作区启动浮层）。

#### 5.1.4 右侧操作按钮

右侧区域包含连接状态指示器与四个操作按钮（从左到右）：

1. **连接状态：** 显示当前 WebSocket 连接状态（已连接 / 重连中 / 断开）。
2. **快速操作按钮：** 搜索图标 + "Quick Actions" 文字。打开命令面板（`Ctrl/Cmd + K`）。
3. **终端面板切换按钮：** PanelBottom 图标。切换底部终端面板的可见性；激活时按钮高亮。
4. **侧边栏切换按钮：** PanelLeft 图标。切换左侧代码侧边栏的可见性；激活时按钮高亮。
5. **设置按钮：** 齿轮图标。导航到设置页面。带有 `data-testid="settings-open"`。

按钮悬停时背景变为稍亮的色调；终端 / 侧边栏按钮根据当前可见性使用 `topbar-btn--active` 或 `topbar-btn--muted` 风格。

#### 5.1.5 空状态

没有工作区打开时，顶栏显示居中空状态，包含一行小标题和提示文字，引导用户打开工作区。

#### 5.1.6 设置路由下的顶栏外观

在设置页面时，顶栏变为：
- **左侧：** 返回按钮，带有返回箭头图标和文字 "Back to App"。
- **居中：** 标题 "Settings"。

### 5.2 全局快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl/Cmd + K` | 切换命令面板 |
| `Escape`（命令面板打开时） | 关闭命令面板 |
| `Ctrl/Cmd + S` | 保存代码编辑器中当前打开的文件 |
| `Ctrl/Cmd + N` | 打开新工作区标签 |
| `Ctrl/Cmd + Shift + [` | 切换到上一个工作区标签 |
| `Ctrl/Cmd + Shift + ]` | 切换到下一个工作区标签 |
| `F`（无修饰键，且未聚焦于文本输入框） | 切换专注模式 |
| `Escape`（在专注模式下） | 退出专注模式 |
| `Cmd + D`（Mac）或 `Alt + D`（Windows/Linux） | 垂直分割当前 Agent 面板 |
| `Cmd + Shift + D`（Mac）或 `Alt + Shift + D`（Windows/Linux） | 水平分割当前 Agent 面板 |

**注意：** 快捷键具有上下文感知能力。`F` 键仅在用户未主动在文本输入框中打字时才切换专注模式。保存快捷键（`Ctrl/Cmd + S`）仅在代码编辑面板可见且有文件打开时生效。

### 5.6 动画与过渡规范

| 属性 | 值 | 用途 |
|------|-----|------|
| 快速时长 | 60ms | 微交互、按钮状态 |
| 普通时长 | 100ms | 标准过渡 |
| 慢速时长 | 150ms | 面板缩放器、较大移动 |
| Ease-out-expo | `cubic-bezier(0.16, 1, 0.3, 1)` | 弹窗出现 |
| Ease-out-quart | `cubic-bezier(0.25, 1, 0.5, 1)` | 通用 UI 过渡 |

**关键帧动画：**

- **脉冲（Pulse）：** 持续透明度振荡（1.0 → 0.5 → 1.0），周期 2 秒。用于运行状态指示点。
- **淡入（Fade In）：** 透明度 0 → 1。用于弹窗遮罩。
- **缩放入（Scale In）：** 缩放 0.95 → 1.0，透明度 0 → 1。用于弹窗卡片。
- **滑入（Slide In）：** X 轴从 100% → 0，带透明度。用于 Toast 通知。
- **旋转（Spin）：** 360 度旋转，周期 0.8 秒，线性，无限循环。用于加载旋转器和检查指示器。
- **闪烁（Shimmer）：** 背景位置偏移，周期 1.5 秒。用于骨架屏加载器。
- **淡入上移（Fade In Up）：** Y 轴从 10px → 0，带透明度。用于列表项出现。
- **右滑入（Slide In Right）：** X 轴从 20px → 0，带透明度。用于面板内容。

**性能规则：** 在面板调整操作期间，面板内容上的所有过渡和动画会临时禁用，以保持流畅的调整体验。

## 6. 移动端外壳

### 6.1 触发条件

`useViewport()` 在视口宽度 ≤ 899px 时返回 `'mobile'`，由 `app.tsx` 中的 `ShellSwitch` 切换到 `MobileShell`。视口动态变化时（旋转设备 / 调整窗口）会自动切换 Shell，UI 状态原子持久化保证切换不丢失。

### 6.2 整体布局

```
┌──────────────────────────────────────┐
│ MobileTopBar（工作区抽屉、设置入口） │
├──────────────────────────────────────┤
│                                      │
│   当前激活会话视区（SessionCard）    │
│   - 进度条 / 状态徽标                │
│   - 终端嵌入                         │
│   - MobileSupervisorBadge（条件）    │
│                                      │
├──────────────────────────────────────┤
│   MobileDock                         │
│   [Agent] [文件] [终端]              │
└──────────────────────────────────────┘
```

抽屉与浮层（MobileSheet）覆盖整个屏幕高度，支持下滑关闭，并自动适配虚拟键盘的 visual viewport 偏移。

### 6.3 MobileDock

底部固定导航栏，三个图标按钮：

| 图标 | 标签 | 行为 |
|------|------|------|
| `Bot` | Agent | 打开 MobileAgentSheet（会话切换 / 启动） |
| `FolderOpen` | 文件 | 打开 MobileFilesSheet（文件树 / 编辑器 / Git diff） |
| `TerminalSquare` | 终端 | 打开终端 sheet |

当前激活的项以 `mobile-dock__item--active` 样式高亮。

### 6.4 MobileTopBar 与工作区抽屉

- 顶栏左侧显示当前工作区名称，点击展开 MobileWorkspaceDrawer。
- 抽屉中列出所有打开的工作区，可切换、关闭，或触发"新建工作区"。
- 顶栏右侧通常是设置按钮或快速操作；具体按钮基于上下文（编辑器打开时显示编辑器 header actions）。

### 6.5 MobileSheet 通用浮层

所有移动端浮层（文件、终端、Agent、Supervisor、设置编辑、工作区启动）都基于 `MobileSheet` 组件渲染：

- 顶部 kicker + title + 关闭按钮
- 主体可滚动，支持 `fullscreen` 与 `flush` 等修饰类
- 自动 `region` ARIA 标签，方便屏幕阅读器
- 通过 `useVisualViewportInset` 自动让位虚拟键盘

### 6.6 MobileSelectSheet

通用选择器组件，统一了"切换工作区"、"切换终端"、"切换 Agent"等操作的交互。支持分组、操作行（含主操作、次操作）、新建项快捷入口。

### 6.7 移动端 Agent 会话

- `MobileAgentSheet` 列出当前工作区的所有会话与启动入口。
- 选中会话后切换主区 SessionCard，URL 不变。
- 进度条、状态徽标、Supervisor 徽章均以紧凑样式呈现，更适合 ≤ 360px 宽度。
- 完成通知优先采用浏览器系统通知；移动浏览器若不支持，会以应用内 toast 兜底（参见第 16 章）。

### 6.8 移动端编辑器与 Git Diff

`MobileFilesSheet` 内含三种视图：

- **root：** 文件树 + Git diff Tab 切换
- **editor：** Monaco 编辑器全屏；顶部显示路径与保存按钮
- **diff：** 单文件 Git diff 全屏

通过 `mobile.files.tabs` 子标签在文件树与 Git 视图间切换。

## 7. 认证系统

### 7.1 用途

对于暴露在网络上（远程服务器、共享机器）的部署，认证系统提供单密码访问控制，防止未经授权的访问。

### 7.2 认证流程

#### 7.2.1 状态

认证页面经历以下状态：

1. **加载中：** 确定认证状态时显示旋转加载器。
2. **未配置：** 如果服务器未设置认证，告知用户应用在没有认证的情况下运行。
3. **登录：** 标准登录界面，带有密码短语输入框。
4. **已封锁：** 用户 IP 因多次失败尝试被锁定。
5. **不可用：** 无法连接到认证服务。
6. **解锁中：** 成功认证过程中的过渡状态。

#### 7.2.2 登录页面

登录页面包含：

- **产品品牌：** 产品名称和版本，显示在顶部。
- **密码输入框：** 文本输入框，占位符提示输入密码短语。
- **提交按钮：** 主要操作按钮，标签为 "Sign In"。
- **错误消息（条件显示）：** 当凭证无效时在输入框下方显示，使用危险色样式。
- **安全信息卡片**（登录表单下方）：
  - **会话策略：** 显示会话空闲超时时间和最大会话生命周期。
  - **允许的路径：** 列出已认证会话允许访问的目录路径。

#### 7.2.3 预览外壳

在认证页面时，登录卡片后方会显示工作台 UI 的线框预览。此预览由占位条和块组成，模拟顶栏、左侧边栏、主内容区域和右侧面板，让用户在登录后能看到界面样式的视觉暗示。

### 7.3 安全策略

| 策略 | 详情 |
|------|------|
| 失败尝试锁定 | 24 小时窗口内累计 10 次失败登录将导致 IP 被封禁 24 小时（实现见 `auth/login-protection.ts`：`LOGIN_FAILURE_LIMIT=10`、`LOGIN_WINDOW_MS=24h`、`LOGIN_BLOCK_MS=24h`） |
| 客户端 IP 解析 | 优先使用 `x-forwarded-for` 第一段；否则回退到 socket IP |
| 会话 Cookie | HttpOnly Cookie（默认名 `coder_studio_auth`），值在客户端 URL 编码 |
| 会话过期 | 后端在认证插件中维护服务端会话仓库 `AuthSessionRepo`，超时后请求会被拒绝并要求重新登录 |
| CLI 管理 | 通过 `coder-studio auth ban-list` / `auth unblock --ip <ip>` 管理封禁列表，方便服务器侧解禁 |

### 7.4 错误码

| 错误码 | 用户可见消息 |
|--------|-------------|
| `invalid_credentials` | "密码不正确" |
| `session_expired` | "您的会话已过期，请重新登录。" |
| `session_missing` | "没有活跃的会话，请登录。" |
| `ip_blocked` | "您的 IP 因多次失败尝试已被封锁。" |
| `auth_unavailable` | "认证服务当前不可用。" |
| `auth_not_configured` | "此部署未配置认证。" |

### 8.2 工作区启动

#### 8.2.1 触发方式

#### 8.2.2 工作区启动浮层

桌面端为模态对话框，移动端为全屏 MobileSheet。简化后的启动流程**只包含本地目录选择器**：

- **头部：** kicker（"START WORKSPACE"）、当前路径标题与提示文字。
- **文件夹浏览器：**
  1. **工具栏：** "主目录"（Home 图标）和"上一级"（ArrowUp 图标）按钮。
  2. **根路径 chips：** 一组常用根目录的快捷按钮，点击直接跳转；当前路径若不在 chips 列表中也会以激活样式显示。
  3. **目录列表：** 每个目录显示文件夹图标、名称和可选项目数提示；单击选中、双击进入；选中行内出现"进入文件夹"按钮。
  4. **加载/空状态：** 加载中显示旋转图标；空目录显示提示文案。
- **错误显示：** 校验失败或权限不足时在 body 底部以红色文字提示。
- **底部操作：** 单一"启动"按钮；未选中目录或正在加载时禁用。

> **已移除：** Local Folder vs Remote Git 选择卡片、Native / WSL 执行目标切换器、独立的运行时校验浮层。Provider CLI 的可用性现在由 `provider-runtime/command-check.ts` 在启动会话时按需检查，UI 仅在缺失时给出错误提示。

#### 8.3.1 布局

- **居中卡片：**
  - kicker（"开始使用"）

    | `Zap` | 以 Agent 为核心的 AI 编码 | `welcome.features.agent_first` |
    | `GitBranch` | 内置 Git 工具 | `welcome.features.git_tools` |
    | `Terminal` | 集成终端 | `welcome.features.terminals` |

### 8.4 工作区生命周期

| 操作 | 行为 |
|------|------|
| 打开 | 创建新标签，初始化 Agent 面板、文件树和终端 |
| 切换 | 保留所有状态（Agent 会话、终端输出、编辑器状态）；工作区在后台继续运行 |
| 关闭 | 终止所有 Agent 会话，关闭终端，移除标签 |
| 恢复 | 如果应用在工作区活跃时重新加载，工作区尝试恢复之前的状态 |

### 8.5 工作区面板布局持久化

每个工作区独立持久化以下布局状态（按工作区 ID 存储于 localStorage）：

- 左侧侧边栏宽度 / 是否折叠
- 底部终端面板高度 / 是否可见
- Agent 面板分割树（嵌套比例）
- 当前激活的 Agent 会话与 Supervisor 配置

切换工作区或刷新页面后会精确恢复，避免每次回归默认布局。

### 8.6 多标签并发控制（Fencing）

当应用在多个浏览器标签页中打开时，控制器/观察者协议管理哪个标签页拥有写入权：

- 当前控制器持有 fencing token，所有写命令携带该 token。
- 其他标签为**观察者**，仅接收事件流；UI 显示 `ObserverBanner`（"只读模式 — 另一个标签页正在控制"）并提供"接管控制"按钮。
- 控制器周期性发送心跳；超时则观察者可以基于截止时间发起接管。
- 标签页 unload / hidden 切换都会触发控制权释放或心跳频率调整。

> 控制权 UI 文案：`fencing.observer_mode`、`fencing.takeover`、`fencing.takeover_failed`。

## 9. Agent 会话管理

### 9.1 概述

Agent 会话是工作区的核心交互单元。每个会话在自己的进程中运行一个 AI 编码 Agent（Claude 或 Codex），并带有专用的终端用于输入/输出。多个 Agent 会话可以在单个工作区内并行运行，以分割面板布局排列。

### 9.2 Agent 面板状态

每个 Agent 面板可以处于以下状态之一：

| 状态 | 视觉表现 |
|------|----------|
| **草稿** | 启动卡片，带有 Provider 选择按钮（Claude、Codex）。尚未启动。 |
| **运行中** | 活跃终端，流式输出。状态点脉冲绿色。进度条动画。 |
| **空闲** | 终端可见但未主动产生输出。状态点为静态。 |
| **已中断** | 会话被手动中断。状态指示器反映中断状态。 |
| **不可用** | 错误状态。显示错误消息、原因和"移除"按钮。 |

### 9.3 Agent 面板布局

#### 9.3.1 面板卡片结构

每个 Agent 会话显示在卡片内（`.agent-pane-card`），具有以下垂直结构：

1. **进度条：** 卡片最顶部的一条细线（3px 高度）。
   - "live" 或 "loading" 状态为强调蓝色。
   - "error" 状态为危险粉色。
   - 宽度动态变化：最小 14%，活跃运行时 34%，否则 6%。

2. **面板头部：** 紧凑头部，包含：
   - **会话点：** 小彩色点，指示状态（绿色 = 活跃，灰色 = 空闲，蓝色 = 排队，弱化 = 关闭）。
   - **标题：** 大写，11px，等宽字体，字间距 0.5px。显示会话标识符。
   - **Provider 徽章：** 小标签显示 Agent Provider 名称（如 "Claude"、"Codex"）。
   - **状态标签：** 小标签显示当前会话状态（如 "Running"、"Idle"、"Queued"）。
   - **操作按钮**（右对齐，悬停时可见）：
     - 垂直分割图标
     - 水平分割图标
     - 关闭（X）图标——悬停时变红

3. **终端区域：** 嵌入终端（xterm.js），填充卡片剩余空间。支持交互模式（用户可以输入命令）和只读模式（仅输出）。

#### 9.3.2 分割面板布局

- **垂直分割：** 将中央面板分为左右两个面板。由垂直分割按钮或 `Cmd/Ctrl + D` 触发。
- **水平分割：** 将中央面板分为上下两个面板。由水平分割按钮或 `Cmd/Ctrl + Shift + D` 触发。
- **调整大小：** 分割分隔条宽 8px，可拖动。拖动调整相邻面板的相对大小。
- **嵌套分割：** 面板可以递归分割，允许在单个工作区内进行复杂的多面板布局。

### 9.4 草稿会话启动

创建新面板时（通过 "+" 操作或分割），它以**草稿**面板开始：

- 显示启动卡片（`.agent-draft-launcher`），带有每个可用 Provider 的按钮。
- 每个 Provider 按钮显示 Provider 的徽章标签和显示名称。
- 点击 Provider 按钮启动该 Provider 的新 Agent 会话。
- 选择 Provider 后，草稿面板被活跃会话面板替换。

### 9.5 会话追踪

每个活跃会话追踪以下元数据：

| 属性 | 描述 |
|------|------|
| 状态 | 当前生命周期状态（idle、running、interrupted） |
| 模式 | 操作模式（branch 或 git_tree） |
| 恢复 ID | 用于恢复之前会话的标识符 |
| 最后活跃时间 | 最近活动的时间戳 |
| 完成率 | 完成进度，以进度条显示 |

### 9.6 会话生命周期事件

会话发出以下生命周期事件：

| 事件 | 触发时机 |
|------|----------|
| `session_started` | 新 Agent 进程启动时 |
| `turn_completed` | Agent 完成一轮编码请求时 |

### 9.7 会话恢复

- **归档：** 过去的会话被记录，可以在归档历史中查看。
- **恢复：** 可以使用恢复 ID 恢复之前的会话，恢复上下文。
- **移除：** 不可用或出错的会话可以从工作区中移除。

### 9.8 空闲策略

每个工作区维护一个每工作区级别的空闲策略：

| 设置 | 描述 |
|------|------|
| 是否启用 | 空闲策略是否激活 |
| 空闲分钟数 | 无活动多少分钟后将会话标记为空闲 |
| 最大活跃会话数 | 进入压力模式前允许的最大会话数 |
| 压力模式 | 同时运行过多会话时的行为 |

会话在配置的空闲时间后被标记为空闲。当空闲会话完成工作时，可以触发完成提醒。

## 11. Git 集成

### 11.1 Git 变更面板

通过左侧边栏的 "Git Diff" 标签访问。

#### 11.1.1 头部

- **分区标签：** "SOURCE CONTROL"，大写，10px，宽字间距。
- **分支 Chip：** 显示当前 Git 分支名称，带有分支图标。

#### 11.1.2 工具栏

五个操作按钮（从左到右）：

1. **刷新：** 重新扫描 Git 状态并更新变更列表。
2. **全部暂存：** 暂存所有未暂存的变更。
3. **全部取消暂存：** 取消暂存所有已暂存的变更。
4. **全部丢弃：** 丢弃所有未暂存的变更（触发确认对话框）。
5. **提交：** 提交已暂存的变更。未输入提交信息时禁用。

#### 11.1.3 提交信息输入

工具栏下方的文本区域（最小高度 30px），用于输入提交信息。

#### 11.1.4 变更分组

变更按三个分组组织：

1. **已暂存：** 已为下次提交暂存的文件。
2. **变更：** 已修改但尚未暂存的文件。
3. **未跟踪：** Git 尚未跟踪的新文件。

每个分组有一个头部，显示分组标签和其中的项目数。

#### 11.1.5 变更行

每个文件变更显示为一行，包含：

- **文件图标：** 基于文件类型着色。
- **文件名：** 变更文件的名称。
- **父路径：** 文件所在的目录。
- **状态徽标：** 彩色徽标，指示变更类型：
  - 已暂存：绿色（`#78d7b2`）
  - 已修改：橙色（`#f1b86a`）
  - 未跟踪：蓝色（`#6cb6ff`）
  - 已删除：红色（`#ff9eb0`）
- **操作按钮（每个文件）：** 暂存、取消暂存或丢弃（根据上下文）。

#### 11.1.6 单文件操作

| 操作 | 行为 |
|------|------|
| 暂存 | 将文件的变更添加到暂存区 |
| 取消暂存 | 从暂存区移除文件的变更 |
| 丢弃 | 将文件的变更恢复到最后提交的状态（触发确认对话框） |

#### 11.1.7 批量操作

| 操作 | 行为 |
|------|------|
| 全部暂存 | 一次性暂存所有未暂存的变更 |
| 全部取消暂存 | 一次性取消暂存所有已暂存的变更 |
| 全部丢弃 | 一次性丢弃所有未暂存的变更（触发确认对话框） |

### 11.2 Git 差异审查

在 Git 变更面板中选中一个文件时，代码编辑器面板切换到差异模式：

- **Monaco 差异编辑器：** 并排视图，左侧显示原始内容，右侧显示修改后的内容。
- **新增行：** 绿色高亮。
- **删除行：** 红色高亮。
- **修改行：** 同时显示删除和添加指示器。

### 11.3 Worktree 检查

一个用于检查仓库关联 Git Worktree 的弹窗。

#### 11.3.1 头部信息

- **Worktree 名称：** 显示为弹窗标题。
- **分支 Chip：** 显示此 worktree 所在的分支。
- **路径 Chip：** 显示 worktree 的文件系统路径。
- **状态 Chip：** 指示 worktree 是 "dirty"（有未提交变更）还是 "clean"。

#### 11.3.2 标签

三个标签用于查看 worktree 的不同方面：

1. **状态标签：**
   - 显示 worktree 路径、分支和状态。
   - 列出各个文件变更及其状态。

2. **差异标签：**
   - 显示 worktree 中变更的文本差异。
   - 以 `<pre>` 块渲染，带有差异格式。

3. **树标签：**
   - worktree 内容的文件树视图。
   - 使用与主文件浏览器相同的 TreeView 组件。

## 12. 终端系统

### 12.1 概述

应用提供两种类型的终端：

1. **Agent 终端：** 嵌入在每个 Agent 会话面板中，显示 Agent 的进程输出。
2. **Shell 终端：** 底部面板中的独立终端，用于运行任意命令。

### 12.2 Shell 终端面板

位于工作区页面底部，Agent 面板下方。

#### 12.2.1 布局

- **进度条：** 面板顶部的细线（3px 高度），类似 Agent 面板进度条。

- 一条消息："No terminal yet"

### 12.3 Agent 终端

每个 Agent 会话有自己的嵌入终端：

- **类名：** `.agent-pane-xterm`
- **渲染模式：**
  - **直接 xterm：** 通过 xterm.js 的标准终端渲染。
  - **转录模式：** 隐藏的 xterm 加上可见的 `<pre>` 文本覆盖层，以提高历史输出的可读性。
- **交互模式：**
  - **交互：** 用户可以在终端中输入命令。
  - **只读：** 终端仅显示输出；不接受用户输入。

### 14.4 通用设置

#### 14.4.1 Agent 默认值

- **默认 Provider：** 药丸选择器（一组切换按钮），列出可用 Provider（Claude、Codex）。决定创建新 Agent 会话时预选的 Provider。

#### 14.4.2 完成通知

- **完成通知开关：** 启用或禁用 Agent 会话完成事件，影响 Toast、系统推送与声音三类通道（详见 §16）。
- **完成提示音开关：** 单独控制是否在通知触发时播放 `task-complete.wav`，通道选择不变。
- **通知权限状态：** 显示当前浏览器 `Notification.permission` 的可用性（`available` / `limited` / `unsupported`）以及"请求授权"按钮。
- **关闭按钮：** 设置面板内嵌的关闭入口，桌面端返回主面板，移动端关闭 MobileSheet。

> 设置变更通过 `settings.update` 命令立即下发；本地键名为 `notifications.enabled`、`notifications.soundEnabled`。

### 14.5 Provider 设置

#### 14.5.1 Provider 切换

顶部一排药丸式 Tab，列出注册表中所有 Provider（当前为 Claude / Codex）。切换 Provider 时保持当前子视图（base/config）。

#### 14.5.2 子导航：基础 / 配置文件

桌面端在 Tab 下方再有一行子导航：

- **基础（`settings.provider.base`）：** Provider 启动参数文本框 + 命令预览。
- **配置文件（`settings.provider.config_file`）：** 内嵌 ConfigEditor，用于编辑 Provider 的本地配置文件。

进入配置文件视图时面板自动切换为 `fill-height` 布局，让编辑器占满剩余高度。移动端没有子导航；基础视图底部提供"打开配置文件编辑器"入口，进入后通过"返回基础设置"链接回退。

- **输入控件：** 多行文本框，每行一条参数。
- **持久化：** 改动通过 `settings.update` 写入 `providers[providerId].additionalArgs`，无需点击保存按钮。
- **命令预览：** 实时调用 `settings.previewCommand`，展示拼接出来的最终命令。连接断开时保持上一次结果。

#### 14.5.4 配置文件编辑器（ConfigEditor）

- **数据源：** 通过 `config.read` / `config.write` 读取并保存本地文件（Codex `~/.codex/config.toml`、Claude 对应的设置文件）。
- **能力：** 提供等宽编辑区、保存反馈、错误提示；拒绝写入越权路径。
- **Codex 漂移联动：** 与 §18 描述的 Codex 漂移检测共用同一份配置文件，"清理漂移项"按钮会触发标准化写入。

### 14.6 外观设置

#### 14.6.2 终端渲染

所有隐藏的 UI 元素恢复到之前的状态。

## 17. Supervisor 系统

### 17.1 用途

Supervisor 是一个自动化评估系统，定期评估 Agent 会话朝着定义目标的进展情况。它可以根据会话状态注入指导、暂停评估或触发重新评估。

### 17.2 Supervisor 状态

| 状态 | 描述 |
|------|------|
| **未激活** | 会话未配置 Supervisor。 |
| **空闲** | 已配置 Supervisor 但当前未评估。 |
| **评估中** | Supervisor 正在积极评估会话进度。 |
| **注入中** | Supervisor 正在向会话注入指导或反馈。 |
| **已暂停** | Supervisor 评估暂时挂起。 |
| **错误** | Supervisor 在评估过程中遇到错误。 |

### 17.3 Supervisor UI

#### 17.3.1 Agent 面板中的 Supervisor 分区

每个带有活跃 Supervisor 的 Agent 会话显示 Supervisor 卡片（`.agent-pane-supervisor-card`），包含：

- **状态属性：** 卡片反映当前 Supervisor 状态（evaluating、injecting、paused、error、off）。
- **标签行：**
  - 徽章勾选图标 + "Supervisor" 标签。
  - 状态标签显示当前状态。

#### 17.3.2 Supervisor 操作

当会话存在 Supervisor 时，可用操作按钮（13px 图标）：

| 按钮 | 图标 | 操作 |
|------|------|------|
| 编辑目标 | 消息方块 | 打开 Supervisor 目标对话框以修改评估标准 |
| 暂停 | 圆形暂停 | 暂停 Supervisor 评估 |
| 恢复 | 播放 | 恢复已暂停的 Supervisor |
| 重试 | 刷新 | 重新尝试失败的评估 |
| 触发 | 上箭头 | 手动触发评估周期 |
| 禁用 | 方形 | 禁用此会话的 Supervisor |

#### 17.3.3 启用 Supervisor

当会话未配置 Supervisor（且会话不在草稿状态）时：

- 显示"启用"按钮（播放图标）。
- 点击以"启用"模式打开 Supervisor 目标对话框。

### 17.4 Supervisor 目标对话框

用于定义和编辑 Supervisor 评估标准的模态对话框。

#### 17.4.1 模式

- **启用：** 首次设置 Supervisor。
- **编辑：** 修改现有 Supervisor 目标。
- **禁用：** 从会话中移除 Supervisor。

#### 17.4.2 布局

- **目标文本区域：** 多行文本区域（5 行，自动聚焦），占位符提示用户描述目标。
- **预览分区：** 只读预览，以格式化代码块（`<pre>`）显示目标文字。
- **操作按钮：**
  - **取消：** 关闭对话框，不保存。
  - **确认：** 主要按钮，保存目标并激活/更新 Supervisor。

### 17.5 Supervisor 周期

每次评估周期以下列状态追踪：

| 状态 | 描述 |
|------|------|
| 排队 | 等待评估 |
| 评估中 | 当前正在评估 |
| 已完成 | 评估成功完成 |
| 已注入 | 已向会话注入指导 |
| 失败 | 评估失败 |

## 21. 设计系统

### 21.1 组件密度

应用在所有表面使用**紧凑**密度布局。带有 `data-density="compact"` 的组件比舒适密度变体具有更紧的内边距和更小的字号。

### 21.2 按钮样式

| 样式 | 类名 | 用途 |
|------|------|------|
| 主要 | `.btn.btn-primary` | 确认操作、启动操作 |
| 默认 | `.btn` | 取消、次要操作 |
| 危险 | `.btn.btn-danger` | 破坏性操作（丢弃、删除） |
| 图标按钮 | `.pane-action` | 面板级操作（分割、关闭） |

### 21.3 交互状态

| 状态 | 处理 |
|------|------|
| 悬停 | 背景变为较亮色调（通过 `color-mix` 计算） |
| 活跃/按下 | 背景进一步变暗，轻微缩小 |

| 禁用 | 降低不透明度（50%），pointer-events none |

### 21.4 面板缩放器

- **宽度：** 主面板分隔条 4px，Agent 分割分隔条 8px。

- **悬停状态：** 背景变为强调色（`#6cb6ff`）。
- **调整大小时：** 面板内容上的所有过渡禁用（`transition: none !important`）以保证性能。`body.is-resizing-panels` 类应用于 body 元素。

### 21.5 模态弹窗

- **遮罩：** 半透明黑色遮罩（`rgba(0, 0, 0, 0.5)`）。
- **卡片：** 从 0.95 缩放入场，带淡入动画。
- **关闭：** 点击模态外部、按 Escape 或点击关闭按钮。
- **密度：** 所有模态使用紧凑密度。

### 21.6 状态徽标与指示器

#### 21.6.1 会话状态点

| 蓝色（`#6cb6ff`） | 未跟踪 |
| 红色（`#ff9eb0`） | 已删除 |

#### 21.6.3 Worktree 状态 Chips

| 类名 | 状态 |
|------|------|
| `.worktree-meta-chip.status.dirty` | 有未提交变更 |

### 21.7 进度条

- **高度：** 3px。
- **行为：** 宽度根据完成率动画变化。
- **颜色：**
  - 活跃/加载中为强调蓝色。
  - 错误状态为危险粉色。
- **最小宽度：** 6%（即使 0% 进度也始终可见）。
- **运行状态：** 活跃运行时最小 34% 宽度。
- **过渡：** 宽度以快速时长（60ms）动画。

## 22. 交互模式

### 22.1 悬停显示模式

多个 UI 元素遵循悬停显示模式，其中次要操作默认隐藏，仅在悬停时出现：

- **标签关闭按钮：** 工作区标签上的 X 按钮默认隐藏，直到悬停标签。
- **面板操作按钮：** Agent 面板头部中的分割和关闭按钮在悬停时出现。
- **文件夹浏览器操作：** 悬停目录行时出现"进入文件夹"操作。

### 22.2 药丸选择器模式

在离散值之间选择的设置选项使用药丸选择器（一行切换按钮）：

- 一次只有一个药丸活跃（单选）。
- 活跃药丸具有不同的背景和边框。
- 点击非活跃药丸激活它并取消之前的选择。
- 用于：默认 Provider、主题、终端渲染、语言。

### 22.3 确认对话框模式

破坏性操作（全部丢弃、关闭有活跃会话的工作区）触发确认对话框：

- **遮罩：** 半透明背景。
- **卡片：** 紧凑模态卡片，包含：
  - **头部：** H3 标题。
  - **主体：** 消息文字，带有可选详情分区（内容 + 时间戳）。
  - **页脚：** 取消按钮（默认样式）和确认按钮（危险样式）。

### 22.4 空状态模式

应用每个主要分区都定义了空状态：

| 区域 | 空状态内容 |
|------|-----------|
| 顶栏（无工作区） | 小标题 + 标签提示打开工作区 |
| 欢迎页面 | 产品描述 + 操作按钮 |
| 终端面板（无终端） | "No terminal yet" + 添加按钮 |
| Agent 面板（草稿） | Provider 选择按钮 |
| Agent 面板（不可用） | 错误标题、原因和移除按钮 |
| Agent 面板（无输出） | "No agent output yet" |
| 命令面板（无结果） | "No results found" |
| 文件搜索（无匹配） | 空下拉框 |

### 22.5 加载状态模式

- **运行时校验：** 检查时状态点蓝色脉冲动画。
- **认证页面：** 加载中状态时显示旋转加载器。
- **骨架屏：** 初始加载期间占位条闪烁动画。
- **Agent 会话：** 初始化期间进度条最小 6% 宽度。

### 22.6 实时同步

应用保持以下内容的实时同步：

- Agent 事件（会话启动、一轮完成）。
- 终端事件（输出片段）。
- 生命周期事件（工作区状态变更）。
- 制品脏事件（Git 变更、Worktree 变更、文件树变更）。

连接中断时自动重连，带有回退机制。

## 23. 边界情况与错误状态

### 23.1 认证错误

| 场景 | 行为 |
|------|------|
| 密码不正确 | 输入框下方显示错误消息；用户可以立即重试 |
| 会话过期 | 用户被重定向到认证页面，显示过期消息 |
| IP 被封 | 显示"已封锁"状态，附带锁定持续时间信息 |
| 认证服务不可用 | 显示"不可用"状态，带有重试选项 |

### 23.2 Agent 会话错误

| 场景 | 行为 |
|------|------|
| Agent 进程启动失败 | 面板进入"不可用"状态，显示错误原因和移除按钮 |
| Agent 进程崩溃 | 终端显示崩溃输出；面板状态反映错误 |
| Agent 会话超时 | 会话标记为空闲；可能触发完成提醒 |

### 23.3 工作区错误

| 场景 | 行为 |
|------|------|
| 目录无法访问 | 工作区启动失败；在启动浮层中显示错误消息 |
| 运行时校验失败 | 工作区启动被阻止；运行时校验浮层显示缺失命令及安装提示 |
| 工作区恢复失败 | 工作区以干净状态打开；之前的会话数据可能丢失 |

### 23.4 Git 错误

| 场景 | 行为 |
|------|------|
| 非 Git 仓库 | Git 变更面板显示空状态，提供初始化 Git 的引导 |
| Git 命令失败 | 错误显示在相关分区（如提交失败） |
| 合并冲突 | 有冲突的文件在变更列表中高亮 |

### 23.5 终端错误

| 场景 | 行为 |
|------|------|
| PTY 分配失败 | 终端显示错误消息和重试选项 |
| 终端进程意外退出 | 终端显示退出码和创建新终端的提示 |

### 23.6 并发冲突

| 场景 | 行为 |
|------|------|
| 两个标签页尝试控制同一工作区 | 控制器/观察者协议确保只有一个标签页有写入权限；另一个标签页观察 |
| 控制器心跳错过截止时间 | 观察者启动基于截止时间的交接协议进行接管 |
| 活跃会话期间页面卸载 | 控制器优雅释放；工作区状态保留 |

### 23.7 网络中断

| 场景 | 行为 |
|------|------|
| WebSocket 断开 | 自动重连，带有回退；断开连接期间事件缓冲 |
| 服务器无法访问 | Agent 会话在本地继续运行；UI 显示连接状态 |

### 23.8 文件系统错误

| 场景 | 行为 |
|------|------|
| 文件被外部删除 | 文件树通过文件观察器自动更新；编辑器中打开的文件显示过期状态直到刷新 |
| 文件权限被拒绝 | 尝试打开或保存文件时显示错误 |

## 附录 C：无障碍考量

| 领域 | 建议 |
|------|------|
