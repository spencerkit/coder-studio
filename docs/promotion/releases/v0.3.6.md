# Coder Studio v0.3.6

## Why this patch matters

`v0.3.6` looks like a small patch from the package changelog, but the shipped product changes are much broader. This release makes Coder Studio more dependable on phones and tablets, reduces session conflicts when the same workspace is opened in multiple tabs, and gives the supervisor workflow better scheduling controls.

In practice, this release means:

- mobile terminal lines can be copied directly with a long press, without entering a separate copy mode
- only one active browser session keeps control of a workspace at a time, with cleaner recovery after reconnects or tab handoff
- supervisor scheduling is easier to use with a built-in date and time picker plus stronger execution policy persistence
- theme and UI polish improvements make the workspace feel more intentional across desktop and mobile

## Included in v0.3.6

- add mobile terminal long-press line copy with stronger touch hit testing and E2E coverage
- add single-active session gating and activation recovery to prevent stale tabs from holding the live workspace session
- add a date and time picker for supervisor scheduled execution, plus persistence and backend handling for execution policy settings
- add the new theme skin system and shared icon styling improvements across the workspace UI
- fix several mobile and settings UI regressions, including switch alignment, popover visibility, session reentry, and worktree refresh behavior
- refresh the README, demo assets, and release narrative structure so the published project materials match the current product

## Who benefits most

- users who primarily access Coder Studio from mobile browsers
- developers who keep the same workspace open across multiple devices or tabs
- anyone relying on supervisor automation for longer-running coding workflows
- evaluators deciding whether Coder Studio is mature enough for day-to-day AI-assisted development

## Install or upgrade

```bash
npm install -g @spencer-kit/coder-studio
coder-studio open
```
