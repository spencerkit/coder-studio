# Coder Studio v0.5.6

## 中文

### 这个版本为什么重要

`v0.5.6` 发布 `v0.5.5` tag 之后合入 `main` 的 canvas 与 workspace runtime 更新，并补齐发布验证中发现的测试 fixture 与样式 token 问题。

实际体验上，这个版本意味着：

- workspace 可以承载 canvas 文件、架构图和报告画布
- canvas 视图支持批注、overlay、快照路径和 PNG 导出辅助能力
- runtime、terminal profile、WSL bridge 与自动化入口的装配更完整
- code editor tabs、workspace refresh、memory panel 和移动端相关交互更稳定

### 这个版本包含哪些变化

- 新增 canvas domain、服务端路由、存储仓库、渲染组件和嵌入式 canvas/snapshot 路径
- 新增报告图表渲染、canvas scene registry、overlay/comment layer 和 PNG export helper
- 扩展 runtime contract、remote protocol、WSL bridge contract 与 terminal/runtime 相关测试
- 改进技能挂载、内置 canvas skill 定义、workspace refresh 和 editor tab 管理
- 修复发布验证中的 editor surface 测试 fixture 与 canvas 样式 token guard 问题

### 谁最受益

- 需要在 Coder Studio 内查看或维护架构图、报告画布的用户
- 依赖 canvas 批注、导出和嵌入式预览链路的用户
- 在 Windows/WSL 或多 runtime 环境中调试 workspace 的开发者
- 需要更稳定 editor tabs、workspace refresh 和技能挂载体验的日常用户

### 安装或升级

```bash
npm install -g @spencer-kit/coder-studio@latest
coder-studio open
```

## English

### Why this release matters

`v0.5.6` publishes the canvas and workspace runtime updates that landed on `main` after the `v0.5.5` tag, with follow-up fixes for release verification fixtures and style tokens.

In practice, this release means:

- the workspace can handle canvas files, architecture diagrams, and report canvases
- canvas views support comments, overlays, snapshot routes, and PNG export helpers
- runtime, terminal profile, WSL bridge, and automation entry wiring are more complete
- code editor tabs, workspace refresh, memory panel, and mobile interactions are more stable

### Included in v0.5.6

- add canvas domain models, server routes, storage repositories, rendering components, and embedded canvas/snapshot paths
- add report chart rendering, canvas scene registry, overlay/comment layers, and PNG export support
- extend runtime contracts, remote protocol, WSL bridge contracts, and terminal/runtime test coverage
- improve skill mounting, the builtin canvas skill definition, workspace refresh, and editor tab management
- fix release verification fixtures and canvas style token guard failures

### Who benefits most

- users who view or maintain architecture diagrams and report canvases inside Coder Studio
- users relying on canvas comments, export, and embedded preview flows
- developers debugging workspaces in Windows/WSL or multi-runtime environments
- daily users who need steadier editor tabs, workspace refresh, and skill mounting behavior

### Install or upgrade

```bash
npm install -g @spencer-kit/coder-studio@latest
coder-studio open
```
