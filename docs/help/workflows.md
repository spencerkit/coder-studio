# 常见工作流

这篇文档按任务场景组织，回答"我想做 XX，应该怎么操作"的问题。

## 这篇文档解决什么问题

以任务为线索的快速操作指南，适合熟悉界面后查找具体步骤。

## 前置条件

- Coder Studio 已安装并启动
- 已配置至少一个 Provider

## 打开一个本地项目并开始工作

1. 启动服务：`coder-studio open`
2. 浏览器中点击"打开工作区"
3. 在目录选择器中找到你的项目目录并确认
4. 项目加载后，点击"创建会话"选择 Provider
5. Agent 会话启动后，你就可以通过终端输入指令开始协作

## 启动一个新的 Agent 会话

- **桌面端**：在 Agent 面板中点击创建会话，选择 Provider
- **移动端**：点击底部 Dock 的 Agent，然后点击创建会话

每个会话是独立的，可以在同一工作区内并行运行多个会话。

## 在 Agent 运行时查看文件和终端

Agent 工作期间，你可以：

- 通过左侧文件树查看被修改的文件
- 通过底部终端面板中的 Agent 终端观察 Agent 输出
- 同时创建 Shell 终端来独立验证 Agent 的成果

## 查看 Git 变更

1. 在左侧面板切换到 Git 标签
2. 查看当前分支名称和变更列表
3. 点击某个文件可以查看差异内容
4. 差异视图支持在中央区域查看具体变更

## 修改 Provider 启动参数

1. 点击顶栏的设置按钮
2. 进入 Providers 页面
3. 选择对应的 Provider
4. 在文本框中添加每行一个额外参数
5. 通过 Command Preview 确认最终命令

## 在桌面端和移动端之间切换使用

Coder Studio 的服务运行在本机上，通过同一个 IP 和端口访问：

- 桌面端：打开 `http://localhost:<端口>`
- 移动端：打开 `http://<本机IP>:<端口>`（需要设备在同一网络）

服务无需切换，界面会自动适配。

## 结束工作前建议检查什么

- 检查 Agent 是否处于空闲状态（避免意外中断）
- 检查是否有未保存的文件更改
- 检查 Git 变更列表，必要时进行提交
- 如果不再需要该工作区，点击顶栏标签上的 X 关闭
