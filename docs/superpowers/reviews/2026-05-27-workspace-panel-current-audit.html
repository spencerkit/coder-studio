和最初视觉稿的差异

这里不做“像素要求”，只指出你会直接感知到的主要偏差。

Mockup Explorer

Initial Mockup

最初视觉稿是单一左栏叙事：header、tabs、toolbar、content 在一个连续层级里，不是 activity rail 和 panel body 分开的写法。

Mockup Git

Initial Mockup

Git 在最初稿里和 Explorer 共用明显更多的骨架语言，而当前实现里 Git 仍是更独立的一块。

1. 结构语法变了，不只是细节没到位

最初稿更像单一侧栏容器内部切 tab；当前实现是 activity rail + panel content 的二段式结构。这不是删标题就能接近的。

2. 当前版本的变化主要停留在“修边”

标题去掉了，圆角和框感收掉了一部分，但 Explorer / Search / Git 的内部 grammar 没一起重建，所以整体气质变化有限。

3. Git 和 Explorer 仍不是同一设计语气

Explorer 更偏树控件，Git 更偏表单 + section 列表，Search 又更像工具页。这就是你说“完全不是一回事”的根因。

4. Search 功能没丢，但风格没回到系统里

行为完整，不是功能性回退；问题是它还没有被纳入统一的 panel grammar。

建议的统一方向

如果一起改，方向不是继续微调 header，而是重做同一套 compact panel grammar，再套到 Explorer / Search / Git / Mobile。

  • 统一 section header、row 高度、control 尺寸、选中态和折叠态。
  • Explorer、Search、Git 都保留真实功能，但用同一套行密度和层次节奏表达。
  • 移动端沿用同一家 grammar，不再单独发明一套视觉语气。
  • Search 必须继续保留文件分组、折叠、行号、命中预览、命中高亮。
